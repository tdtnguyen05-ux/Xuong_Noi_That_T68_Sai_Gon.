# Website Xưởng nội thất T68

Website tĩnh gồm 5 trang: Trang chủ, Giới thiệu, Dự án, Tư vấn thiết kế và Liên hệ.

## Cấu trúc
- `index.html`: Trang chủ
- `gioi-thieu.html`: Giới thiệu
- `du-an.html`: Danh mục hình ảnh tham khảo
- `tu-van.html`: Biểu mẫu tư vấn
- `lien-he.html`: Thông tin liên hệ
- `styles.css`: Giao diện xanh navy – vàng ánh kim – trắng kem
- `script.js`: Menu di động và xử lý biểu mẫu
- `assets/t68-logo.png`: Logo T68 do người dùng cung cấp

## Xem thử
Mở `index.html` bằng Chrome hoặc Edge. Cần có kết nối Internet để tải ảnh minh họa từ Unsplash.

## Cập nhật lên GitHub
1. Giải nén ZIP.
2. Mở repository GitHub hiện tại.
3. Chọn Add file → Upload files.
4. Kéo toàn bộ tệp và thư mục bên trong `xuong-noi-that-T68` vào GitHub (bao gồm thư mục `assets`).
5. Chọn Commit changes.

## Lưu ý nội dung
- Hình ảnh nội thất hiện là ảnh minh họa, không phải bằng chứng về công trình T68 đã thực hiện.
- Chỉ công bố thông tin về năng lực, dự án, tiến độ, bảo hành hoặc thành tích khi doanh nghiệp xác nhận.
- Biểu mẫu tư vấn hiện sử dụng mailto để mở ứng dụng email; khách hàng cần tự gửi email.
